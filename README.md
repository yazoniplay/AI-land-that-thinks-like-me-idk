# Think Like Me

A personal writing assistant that learns your writing preferences over time. Designed for a Grade 7 student learning Swedish as a second language (Svenska som andraspråk).

## Starter features
- Swedish-first writing workspace
- Style-aware rewrite prototype
- Feedback controls that teach the writing profile
- Notes library with note context for writing
- Inspectable and resettable local writing profile

## Run locally
`npm install`
`npm run dev`

## Important
The current prototype stores notes and writing preferences in this browser's localStorage. AI generation is currently a clearly labeled demo. Connect a secure server-side AI endpoint before using real model calls; never put provider API keys in frontend code.
